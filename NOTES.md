# NovaMart — Agent 1 (scaffold) notes

## Decisions

- **Next.js 14 App Router, no `src/` dir.** `app/` at repo root per contract. Server components by default; `"use client"` only on Header, Footer (newsletter state), and interactive UI primitives (Modal, QtySelector).
- **Styling is Tailwind 3.4 only.** Design tokens in `tailwind.config.ts`: `brand` (indigo-600 `#4F46E5`, dark `#4338CA`, ink `#1E1B4B`), `deal` amber `#FBBF24`. Inter via `next/font/google` with CSS variable `--font-inter`, wired into `fontFamily.sans`. Restrained palette — no gradients except the dark ink footer; hierarchy via size/weight/whitespace.
- **Only dependency added beyond the Next toolchain: `lucide-react`.** No component libraries, no state libraries, no CSS-in-JS.
- **`lib/cn.ts`** — tiny class-name joiner (avoids pulling in `clsx`).
- **Data layer (`lib/store.ts`)**:
  - All functions are safe to import from server components: every access is guarded with `typeof window`, server returns fallbacks and never writes.
  - Seeding is idempotent and lazy (`ensureSeed()` on first browser call). Products are copied into `novamart_products_override` once so admin edits mutate a local copy while `data/seed.json` stays pristine.
  - Session = signed-in user id in `novamart_session`; `logout()` clears it. Passwords are plaintext in the demo store (documented demo limitation — never do this in production).
  - Wishlist: logged-in users store it on their user record; guests get `novamart_wishlist_guest`.
  - Order numbers: `NM-001001`, `NM-001002`, … via a persisted counter. Status changes in `updateOrder` auto-append a timeline entry.
  - `validateCoupon` is case-insensitive and checks active / expiry / usage limit / min order; returns computed discount + freeShip flag.
- **Seed data** (`data/seed.json`, generated deterministically by `/tmp/gen_seed.py`): 48 products (8 per category), 19 with `compareAtPrice` (~40%), 12 with badges, 8 featured, 5 at zero stock (out-of-stock states), ratings 4.1–4.9, 3 picsum images each, 5–6 specs each, fashion sizes XS–XL / shoe sizes 7–12, 24 reviews spread across 20 products, 4 coupons exactly per contract, store settings (8% tax, $6.99 flat shipping, free over $75).

## For other agents

- Import domain types from `@/lib/types` — shapes are contract-fixed, don't redefine them.
- Use `lib/store.ts` for all data access on the client. On the server (e.g. generateStaticParams) prefer reading `data/seed.json` directly — the store returns empty fallbacks during SSR/prerender. Note: `getProducts()` reflects admin overrides at runtime on the client.
- `format.ts` gives you `currency()`, `formatDate()`, `orderStatusMeta`.
- UI primitives live in `components/ui/` with the exact prop names from the contract (Button variants primary/secondary/outline/danger/ghost; Stars `{value, size}`; QtySelector `{value, onChange, max}`; EmptyState `{icon, title, hint, action}`; SectionHeading `{kicker?, title, sub?, link?}`; Price `{value, compareAt?, size?}`).
- `components/cart/CartShell.tsx` is Agent 3's file but is already imported by `app/layout.tsx` and `components/layout/Header.tsx` — `useCart()` returns `{ items, addItem, removeItem, updateQty, clear, count, subtotal, isOpen, setOpen }` per contract.
- Product images are `https://picsum.photos/seed/…` — `next/image` remote pattern is configured in `next.config.js`.

## Integration fixes (continuation pass, 2026-09-21)

`components/ui/` and `components/layout/` were drafted while other agents' pages already imported them, so a grep sweep over every `@/components/ui/*` and `@/components/layout/*` import was run and the following mismatches were fixed:

- **`Stars`**: drafted as `size?: number`, but all call sites pass `size="sm" | "md"` strings → changed to `size?: 'sm' | 'md' | 'lg'` mapped to 14/16/20 px. Affects ProductCard, product page, ReviewsList.
- **`Select`**: `options` was required, but `app/account/addresses/page.tsx` passes `<option>` children → `options` is now optional; children take precedence, `options` array still works (admin order filters).
- **`components/ui/index.ts` barrel added**: 8 files (cart/checkout/track/order-success/admin-orders, CartDrawer, CouponForm) import named components from `'@/components/ui'`; the barrel re-exports all 12 primitives. Direct-path imports (`@/components/ui/Button`) keep working.
- Everything else matched call sites: Button variants/sizes, Input/Textarea label+error, Card className passthrough, EmptyState `{icon, title, hint, action}`, SectionHeading `{kicker, title, sub, link}`, Price `{value, compareAt?, size?}`, QtySelector `{value, onChange, max?}`, Badge children/variants.
- **Tax scale verified**: `settings.taxRate` is a fraction (`0.08`); `components/cart/cart-utils.ts` and checkout both do `subtotal * taxRate` — consistent.
- `lib/store.ts` public API untouched. `app/layout.tsx` already wrapped children in `<CartShell>` with `<Header/>`/`<Footer/>` — kept as-is.
